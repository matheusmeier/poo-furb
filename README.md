# Programação Orientada a Objetos — FURB

Repositório com exercícios, exemplos de código e diagramas desenvolvidos durante a disciplina de **Programação Orientada a Objetos**, no curso de Bacharelado em Ciência de Dados da FURB.

## Organização

| Diretório | Conteúdo |
|---|---|
| `01-fundamentos-e-classes` | Listas de exercícios iniciais, classes, objetos e relacionamentos |
| `02-exercicios-de-modelagem-e-objetos` | Exercícios da aula 07 |
| `03-testes-unitarios` | Exercícios e testes com JUnit |
| `04-heranca-e-polimorfismo` | Exercícios das aulas 09 e 10 |
| `05-polimorfismo-e-abstracao` | Exercícios da aula 11 |
| `06-colecoes-e-validacoes` | Exercícios da aula 13 |
| `07-manipulacao-de-arquivos` | Exercícios de operações com arquivos e diretórios |
| `08-diagramas` | Diagramas de classes em formato Draw.io |
| `09-simulados` | Implementações práticas de simulados |

## Tecnologias e ferramentas

- Java
- Programação Orientada a Objetos
- JUnit 4 (nos exercícios de testes)
- Draw.io (diagramas de classes)

## Observações

- Os diretórios mantêm a referência às unidades e aulas da disciplina para facilitar a consulta ao material.
- Os códigos representam atividades acadêmicas e podem estar em diferentes estágios de desenvolvimento.
- Os arquivos de configuração específicos do VS Code e as bibliotecas `.jar` foram omitidos para evitar incluir configurações locais e binários no repositório. Para executar os testes da aula 08, configure o JUnit 4 e o Hamcrest no ambiente Java.
- Os PDFs de provas e enunciados foram omitidos; o repositório prioriza os códigos produzidos e os diagramas.
- Antes de publicar, confira se a divulgação dos exercícios e diagramas está de acordo com as orientações da disciplina.

## Objetivo

Documentar o aprendizado e acompanhar a evolução prática nos fundamentos de Java e Programação Orientada a Objetos ao longo da graduação.
